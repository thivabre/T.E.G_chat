# Proyecto TEG - Aplicacion Web

Aplicacion web para la gestion del juego TEG (Tactica y Estrategia de Guerra), con base de datos, consultas y procedimientos almacenados ya implementados.

## Descripcion

Este proyecto consiste en una pagina web que interactua con una base de datos disenada especificamente para el juego TEG. La base de datos, sus consultas (queries) y procedimientos almacenados (stored procedures) ya se encuentran desarrollados.
